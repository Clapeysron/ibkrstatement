# IBKR 账户分析

以长桥资产页面为视觉参考的本地报表看板，支持白天 / 黑夜主题及 PC、手机布局。沿用原有 IBKR Activity Statement CSV/TXT 解析流程，文件在浏览器内处理，不上传服务器。

## 运行

需要 Node.js，无需安装运行依赖，也没有构建步骤：

```sh
npm run serve
```

打开 http://127.0.0.1:4187/，导入中文或英文 CSV/TXT。支持拖放、文件选择、粘贴文本，以及原有示例报表。主题保存在当前浏览器中；真实报表只保存在页面内存，刷新后需重新导入。

## 页面

- **当前持仓**：证券代码/名称、含现金的持仓分布、市值/数量、报表收盘价/成本价、未实现盈亏及占比。手机切换“市值/价格”和“盈亏/占比”两组列。
- **资产盈亏分析**：本月、近 1 月、近 6 月、本年、近 1 年、全部；累计已实现盈亏金额/百分比曲线、成交金额和报表总资产。曲线支持鼠标或触摸拖动，显示所选日期的当日和区间累计已实现盈亏；也可使用左右方向键、Home/End 查看日期，Escape 关闭提示。
- **收益日历**：按年查看月份、按月查看日期；切换金额和百分比。选择日期后可查询当日成交。
- **盈亏总结**：按区间与资产类别查看已实现盈亏明细。
- **盈亏排行榜**：盈利/亏损排名，点击证券查看成交明细。
- **我的资产**：期初资产、入出金、已识别净投入、盈亏额与期末资产关系图，以及净值变化明细。
- **资金记录**：成交款项、关联手续费、入出金、利息、股息和税费。支持日期、币种、类型及关键词筛选。
- **成交查询**：买卖方向、数量、价格、原始成交时间、金额及手续费详情。支持筛选、搜索和分批加载。

证券代码统一使用主标题，名称使用灰色小字；不重复显示“股票”标签，保留期权、外汇与空头等信息。收益日历的日期格及月份格只显示盈亏，不显示成交笔数。

## 计算口径

所有数据截至报表结束日；期间按钮相对于报表结束日计算。若报表范围不足，页面说明仅包含已提供的数据。价格为报表收盘价，不接入实时行情。

1. 曲线、日历、区间总结与排名使用股票及期权逐笔 `baseRealizedPL`。这些是**已实现交易盈亏**，不包含每日持仓浮盈变化或完整账户盈亏。不会重复扣除已包含在已实现盈亏中的佣金。
2. 百分比 = 所选区间累计（或日历当日/当月）已实现盈亏 ÷ **报表期初资产 + 已识别净投入** × 100%。分母在整份报表内固定，必须大于零。这是盈亏占投入比例，不是时间加权收益率。
3. 上方单列的账户收益率来自报表整期 TWR，仅在筛选覆盖整个报表时显示。单份活动报表不提供每日净值时，不推算每日 NAV 或总资产曲线。已取消标普 500 比较。
4. 资产关系图使用 `Change in NAV` 官方汇总。盈亏额 = 期末 − 期初 − 已识别净投入；净投入包括出入金和股票赠与。未提供的其他资产流入显示 `—`，不以残差补齐。与 NAV 不一致时显示差额。
5. 持仓分布按证券本位币绝对市值与报表现金余额的绝对金额计算，列出前五大证券、其他证券与独立现金项。负现金标为“现金借款”；缺失现金不当作零，也不以总资产差额反推。分布不包含应计利息等项目。表格资产占比仍使用持仓本位币市值 ÷ 期末总资产，空头保留负数市值和占比。
6. 跨币种统计沿用原解析器的报表汇率，并非逐笔历史汇率。资金流水以原币显示，因此其折算汇总可能与官方历史换算后的出入金汇总不同。
7. 手续费记录使用关联成交时间，不冒充实际扣款结算时刻。成交查询不包含未成交委托、撤单或状态历史。

示例 CSV 来自原仓库，其中部分汇总与明细不一致。页面保留原始金额并标注示例，不通过回填或缩放对齐。

## 解析兼容

继续使用 `src/parser.js` 和 `src/encoding.js`。保留原输出字段与原有盈亏算法，补充了以下 CSV 中已有内容：

- 报表起止日期和原始生成时间。
- 证券描述、上市交易所和原始持仓成本价。
- 入出金、利息、股息、费用和代扣税日期明细。
- 原始成交时间文字。
- NAV 字段存在性，以区分缺失值和真实零。
- 中文“应计利息变更”“其它外汇换算”字段别名。

额外现金流水缺少汇率时保留原币金额，折算金额为 `null`；原有持仓/成交汇率缺失处理继续严格报错。

## 验证

```sh
npm run check
npm test
```

测试覆盖原解析器、中文/英文报表、币种与手续费、日期筛选、现金分布、缺失数据、盈亏计算、图表日期映射与键盘选择、页面渲染、安全转义及期权详情。

主要前端文件：`src/app.js`（页面和交互）、`src/dashboard-model.js`（展示适配与筛选）、`src/chart-model.js`（图表日期序列与选择）、`src/interactive-chart.js`（图表提示与指针交互）、`assets/styles.css`（主题和响应式布局）。`serve.mjs` 和启动方式保持不变。旧前端的中英文切换和分享图入口已移除；仍支持中英文 CSV 与 JSON 导出。

真实账户报表不应提交到公开仓库。CSV/TXT/表格文件默认被 Git 忽略，仅放行仓库原有的两份示例 CSV 和 `robots.txt`；`ibkr-report*.json` 导出文件、导出目录、截图目录、环境变量文件与常见缓存也已加入忽略规则。导入的报表数据只在浏览器内存中，浏览器仅持久保存主题设置。此工具不是 Interactive Brokers 或长桥官方产品。

最近改动及验证结果见 [修改记录](CHANGELOG.md)。
